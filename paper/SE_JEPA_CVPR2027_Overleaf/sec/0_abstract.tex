\begin{abstract}
Latent world models enable action planning but struggle with distribution shifts after deployment. Test-time adaptation addresses these shifts within an episode, yet resets afterward, forcing agents to repeatedly relearn recurring changes. We find that carrying adapted weights forward fails: consecutive updates are nearly orthogonal (mean cosine 0.018), and inheriting them cuts success from 62\% to 48\%. We therefore retain the observed transitions, not the weight updates. SE-JEPA, inspired by complementary learning systems, pairs fast within-episode adaptation with slow cross-episode consolidation, replaying trajectories into one slow predictor per self-discovered domain. Supervised only by its own prediction errors, it decides what to store and when to trust a learned predictor for planning. We keep the original pretrained weights fixed and learn separate slow predictors as lasting memory across episodes. No shift labels or task boundaries are needed, and both gradient-based and sampling-based planners benefit. SE-JEPA achieves state-of-the-art planning performance, improving held-out success over AdaJEPA by 15.4--17.1 percentage points on unseen PushObj shapes and 15.9--18.7 points on PushT visual shifts across both planners. On rope and granular manipulation, Chamfer distance drops by 48.6\% and 26.7\%, respectively, relative to pretrained DINO-WM. Performance improves further over repeated deployment. The source code will be made public.
\end{abstract}
