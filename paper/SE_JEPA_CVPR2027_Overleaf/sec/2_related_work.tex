\section{Related Work}
\label{sec:related}

\paragraph{World models for control.}
Learned dynamics support control by predicting the consequences of candidate actions. Embed to Control~\cite{watter2015e2c} learns locally linear latent dynamics from images, World Models~\cite{ha2018worldmodels} learns compact recurrent simulators, and PETS~\cite{chua2018pets} combines probabilistic dynamics ensembles with planning. PlaNet~\cite{hafner2019planet} plans directly in a learned latent space; Dreamer and its successors learn behavior through latent imagination~\cite{hafner2020dreamer,hafner2021dreamerv2,hafner2025dreamerv3}. IRIS~\cite{micheli2023iris} models visual trajectories with a token-level Transformer. MuZero~\cite{schrittwieser2020muzero} learns predictions tailored to search, while TD-MPC and TD-MPC2~\cite{hansen2022tdmpc,hansen2024tdmpc2} combine latent dynamics with value learning for continuous control. These approaches establish several ways to turn prediction into action. We study how a visual planner can accumulate predictive knowledge throughout deployment.

\paragraph{Predictive representations and JEPA.}
Self-supervised visual learning supplies reusable features: DINO and DINOv2~\cite{caron2021dino,oquab2024dinov2} learn transferable visual representations, while R3M~\cite{nair2022r3m} learns manipulation features from human video. VICReg~\cite{bardes2022vicreg} addresses representation collapse through variance and covariance regularization. I-JEPA~\cite{assran2023ijepa} learns by predicting target embeddings from image context; V-JEPA~\cite{bardes2024vjepa} extends feature prediction to video. V-JEPA~2~\cite{assran2025vjepa2} scales this approach and adds an action-conditioned model for image-goal robotic planning. For offline visual control, DINO-WM~\cite{zhou2024dinowm} predicts pretrained DINOv2 patch features and optimizes actions toward goal embeddings. Temporal straightening~\cite{wang2026straightening} shapes latent trajectories to improve planning geometry, DDP-WM~\cite{yin2026ddpwm} separates primary dynamics from background updates for efficient prediction, and LeWorldModel~\cite{maes2026lewm} learns predictive embeddings end to end from pixels. Together, these methods develop the representations and dynamics on which latent planning depends. \ours adds persistent learning to this planning loop: experience with unfamiliar conditions is consolidated into predictors that can be retrieved on later encounters. We evaluate this mechanism with both gradient-based and sampling-based action optimization.

\paragraph{Test-time adaptation.}
Test-time training~\cite{sun2020ttt} and entropy minimization~\cite{wang2021tent} adapt a deployed model using unlabeled target data, and continual test-time adaptation follows a changing target distribution~\cite{wang2022cotta}. Control provides a natural self-supervised signal: every executed action yields an observation that checks the model's prediction. AdaJEPA~\cite{wang2026adajepa} uses this signal to update latent dynamics inside MPC, with adaptation reset between episodes. \ours builds on this fast loop and retains its deployment experience through slow consolidation, allowing subsequent episodes to start from a predictor informed by earlier interactions.

\paragraph{Continual learning and complementary memory.}
Complementary learning systems pair rapid hippocampal learning with slow neocortical consolidation~\cite{mcclelland1995cls}. In continual learning, replay revisits earlier experience~\cite{rolnick2019replay}, GEM constrains updates using episodic memory~\cite{lopezpaz2017gem}, and EWC protects parameters important to previous tasks~\cite{kirkpatrick2017ewc}. \ours brings complementary memory into closed-loop predictive control, where retrieving a model changes both the actions taken and the data collected next. Its label-free routing organizes experience into domains, and its readiness gate evaluates each consolidated predictor on episodes it has not yet trained on before using it for planning. This couples knowledge retention to the decisions made during deployment.
