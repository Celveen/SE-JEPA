# 为什么 DINO-WM 的 Color 不低：同目标特征诊断

使用原 VIS50 的 50 个起点/目标对，共 100 张图。在相同物理状态上渲染原始颜色与三种颜色变化，用相同冻结 DINOv2 patch 编码器前向。输入遵循官方 DINO-WM 的 [-1,1] 归一化及 196×196 编码尺寸。没有训练，没有重新规划，也不把这些诊断当作新增成功率结果。

| 条件 | 改变像素占比 | 受影响 patch 特征余弦 | 原始/变色后起点—目标距离相关性 |
|---|---:|---:|---:|
| 红推杆 | 0.293% | 0.9385 | 0.9962 |
| 红物体 | 2.979% | 0.8785 | 0.9813 |
| 红参考标记 | 2.392% | 0.9400 | 0.9891 |

全 patch 余弦分别为 0.9954、0.9720、0.9885，但会受到大量不变背景影响，因此上表另报真正受像素变化影响的 patch。

这些测量表明，红推杆和红参考标记对 DINO 表征中的几何目标关系影响较小，红物体的影响更大。这与原结果红推杆 74%、红物体 46%、红标记 76% 的模式一致，支持特征鲁棒性解释；它不是该解释对成功率影响的因果量化。

red_goal 改的是固定参考标记，真实目标由目标观测中物体和 agent 的位置决定。它不改变物理动力学，也不等同于把真正的目标物体染色。

旧 DINO Color 65.33% 与新版 Ours 约 65.19% 来自不同目标集和统计范围，不能把约 0.14 个百分点当成可靠的优劣差异。旧结果还缺完整的预训练—测试来源映射，因此此前审计没有宣称完全排除泄漏。本次新增随机数据独立生成、无专家来源，并记录种子及轨迹哈希，是进一步排除训练数据重用的实验。

原始数值见 color_feature_analysis.json；代码为 scripts/analyze_dinowm_color_features.py。完整的原始结果重放与官方源码审计位于 reports/dinowm_audit_20261106/。
