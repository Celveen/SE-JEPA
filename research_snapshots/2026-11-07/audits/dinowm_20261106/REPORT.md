# DINO-WM 实验审计：模型一致，评测协议不等同于原文

日期：2026-11-06（北京时间）。本次检查没有训练新模型、没有重新执行正式 CEM 评测、没有改写原始结果。做了固定源码对照、同权重前向检查、颜色目标核验，以及保存动作的物理重放。

## 核心结论

1. **当前结果是 DINO-WM 模型在本项目控制与数据协议下的评测，不是原文的逐项复现。** 最重要的差异是每次重规划前执行的物理步数、规划目标函数，以及 PushObj 的训练/测试形状划分。
2. **没有发现颜色未生效、把 AdaJEPA 适应混入 DINO-WM、真实动作初始化或成功率算错的证据。** 本次重放了 150 个颜色 episode 和 350 个 PushObj episode：成功标记和首次成功步数全部一致，差异为 0。
3. **Color = 65.33% 是 74%、46%、76% 三个结果的平均。** red_goal 实际改变画面里的固定参考标记，不是改变真正的目标物体状态；原文也明确绿色 T 是参考锚点。这一条件不能按“真实目标物体变色”的难度来理解。
4. **完整数据谱系尚不足以证明预训练与测试源轨迹绝对隔离。** 当前能证明训练/验证源索引隔离，并排除已发现相同初态处的同动作轨迹重复；不能把这个有限检查扩大成完全排除泄漏。

## 1. 与原文 / 官方代码的具体差异

官方源码固定到 gaoyuezhou/dino_wm 的提交 0a9492fa12044b852ae9e001cc74604b79c8bb0c。相关源码及 SHA256 保存在 official/。以下区分论文明确描述和该公开代码的默认设置，不把源码默认值当作论文每一项实验的完整运行记录。

| 项目 | 原文或官方代码 | 当前运行 | 含义 |
|---|---|---|---|
| 模型主体 | DINOv2 ViT-S/14 patch + 6 层、16 头 predictor | 相同；总参数 52,319,499 | 主体结构未被替换成其他方法 |
| DINO 编码尺寸 | 196×196，14×14 patch token | 相同 | 输入 224 后缩到 196 是官方行为 |
| 规划预测时域 | goal_H=5 个模型步，frameskip=5，即 25 物理步 | 配置 25 物理步，经转换为 5 模型步 | 这个时域实际一致，不能仅看 YAML 的 5 与 25 |
| 每次执行后重规划 | 官方 plan.py 将 n_taken_actions 设为 goal_H=5 个模型步，即 25 物理步 | n_taken_actions=5 物理步，经转换为 1 模型步 | 本项目控制反馈频率是官方这份配置的 5 倍，可能改善闭环控制 |
| 目标函数 | 论文 A.5 / 官方配置：末端 latent MSE，mode=last | 前 5 次使用末端，之后使用整段加权损失，mode=staged | 优化目标不同；诊断候选排序确实改变 |
| CEM | 官方 plan_pusht.yaml：300 candidates、30 iterations、30 elites | 200 candidates、10 iterations、30 elites | 采样搜索预算不同，不能简单断言净效果一定更容易或更难 |
| MPC 上限 | 该官方配置 max_iter=null | 最多 30 次重规划，即最多 150 物理步 | 官方配置不能直接推导出论文的有限总执行预算 |
| PushObj 数据 | 论文：20,000 条随机轨迹 | 16,000 条训练 + 4,000 条验证；由有接触偏置的专家轨迹重放生成 | 数据分布与原文不同 |
| PushObj 训练轮数 | 论文 Table 12：100 epochs | 用户明确选定统一 3 epochs，固定 epoch 3 | 已授权的预算差异，不是继续训练到 100，也不宜再称原文训练复现 |
| PushObj 形状划分 | 原文 Fig.5 蓝框中的未见测试形状是 L 和 + | 训练 T/L/Z/+；未见 I/square/small_tee | 原文 34% 与本机 62% 或 46% 均不是同一形状划分 |
| PushT 视觉偏移 | 原文 Table 1 的 PushT 为无此六偏移的任务 | VIS50 六视觉偏移 | 原文没有可直接对照的 Color 平均值 |

原文 Figure 5： https://arxiv.org/html/2411.04983v2#S4.F5 。蓝框测试列为 L、+；本地已保存 paper_figure5.png。此前只说“原文 34% 应与本机未见 46% 比”仍不够准确，因为两者连未见形状集合也不同。

## 2. 模型与权重核验

- PushT 使用 OSF 官方发布权重，checkpoint 中 epoch=2；SHA256 与下载收据完全一致：e909f0cec958fc0b49a79f2e85730ae6b5f83dee61a224705f91883eb3bb74c5。
- PushObj 使用本项目完整模型补训的 epoch=3。
- 两份模型总参数均为 52,319,499：冻结编码器 22,056,576，predictor 20,122,600，decoder 10,140,163，proprio embedding 50，action embedding 110。
- 将相同权重严格加载到固定官方源码，在同一观测下对 16 条候选、5 个模型步进行前向对比：视觉和本体预测的最大绝对差均为 0。证据见 model_equivalence.json。这是明确输入上的一致性检查，不是对所有可能输入的形式化证明。
- 没有额外 projector；PushObj action/proprio 的额外 LayerNorm 已关闭，官方 PushT 整模块权重也不会被默认构造参数重新覆盖。
- 实际规划类为 SlowFrozenMPCPlanner，state_in=null。它直接继承普通 MPC；这种配置下不创建 AdaJEPA trainer，也不执行快更新或慢学习。配置文件中残留的 adapt 字段不能据此认定发生了适应。
- debug_dset_init=false，规划初始动作不是保存的真实轨迹动作。真实动作只用于生成可达目标，之后仅使用模型规划的动作。

## 3. Color 的实测结果与任务含义

| 条件 | 成功 / 总数 | SR | 保存动作重放不一致数 |
|---|---:|---:|---:|
| red_agent | 37 / 50 | 74% | 0 |
| red_object | 23 / 50 | 46% | 0 |
| red_goal | 38 / 50 | 76% | 0 |
| 三条件合计 | 98 / 150 | 65.33% | 0 |

150 个颜色 episode 的起点和目标图片，用原动作与同一颜色配置重建后，与保存图片逐像素一致；目标状态误差为 0。每个条件的 50 个起点和 50 个目标图都含有实际红色区域。

颜色参数保存在环境中，在线回放仍然使用同一颜色。red_agent、red_object、red_goal 都同时作用于当前观测和目标观测，不是只把文件夹或配置名字改为 red。

同一 VIS50 组中，DINO CLS、R3M、DDP-WM、LeWM、Frozen、AdaJEPA 的三种颜色条件，与 DINO-WM 的起点/目标状态及像素均完全一致。DreamerV3/IRIS 的 VIS350 缓存也复用了相同状态；64×64 是分辨率适配，不能因此说它们换了另一批目标。与 Ours 新版三种子留出视觉资料的目标集差异，则仍然需要保留。

参见 color_conditions.png：实际 goal observation 中物体应到的位置与固定彩色参考标记的位置不同。DINO-WM 论文 A.1 也明确：绿色 T 不再表示物体目标位置，只充当视觉锚点。因而 red_goal 更准确的名称是 red reference marker。较强的 patch 特征保持几何信息、以及这个参考标记本身不影响动力学，都是高成功率的合理解释，但本次没有用额外配对规划实验量化各因素的因果贡献。

不能仅因 Color 比预期高就降低或舍弃分数；也不能把 65.33% 与另一套目标上 Ours 的 Color 直接作逐样本排名。

## 4. 计分、重放和数据重合检查

- PushObj 350 个 episode 的保存动作已全部重放：成功标记和首次成功步数全部一致。总成功率 62%；已见 74%；当前三种未见形状平均 46%。
- 成功位置条件是 agent 与 object 共四个位置坐标的联合欧氏误差 <20，另要求物体角度误差 <π/9；不是只检查物体位置，也不是使用环境绿色标记的覆盖奖励。
- 当前角度代码用正确的最短弧计算。对于这些角度已包装的目标，它与官方原公式一致；不是通过放宽成功阈值得到更高分。
- 共 500 个重放样本中只有 2 个 PushObj 初始状态本已满足阈值；颜色组没有这种初始即成功的样本。
- 训练形状确认为 T/L/Z/+，每种 4000 条。训练源索引范围 0–15999；验证源索引范围 16000–18684，源索引交集为 0。
- 在 350 个 PushObj 测试初态与训练状态张量的精确匹配筛查中发现 5 个相同数值初态。它们都是 offset=0 的公共初始布置，匹配也只发生在训练轨迹第 0 帧；后续 25 步动作均不同，最小最大动作差仍超过 22 像素。L 和 square 两例的匹配还来自不同形状。不能据此认定存在完全重复的训练轨迹。
- 测试文件只有 ep_idx/offset，缺与重建训练集 source_index 同一命名空间的谱系映射。因此当前审计不能给出“预训练—测试完全无源轨迹重合”的强保证。详细筛查见 data_overlap_screen.json 和 exact_state_match_followup.json。

## 5. 论文和后续实验应如何处理

1. 将现有数值标为 DINO-WM under the shared project MPC protocol，保持权重来源、训练预算和目标集合清楚。此前“模型按原版规模对齐”不等于“整个实验按原文复现”。
2. 在写入主表前区分本项目共同控制器下的比较和文献原值；不用原文 34% 推断本机 62% 一定虚高，或者反向宣称复现超过原文。
3. 将 red_goal 的含义写为固定参考标记变红，并准确描述联合位置成功判据。
4. 若要量化控制协议带来的收益，下一步应固定权重、同一批目标与随机数方案，单独对照 last/staged 和执行 5/25 个物理步的组合。这个问题首先是评测协议问题，不需要先增加训练 epoch。
5. 本次未自动启动上述新的正式评测，也未改写或覆盖任何原始成功率。只有原始结果重放、固定输入前向诊断和离线数据核查。
